# งานที่ 1: โหมดแข่งขัน 4 คน — KUHU NET

เอกสารสำหรับผู้พัฒนาคนที่ 1: เพิ่มโหมด FFA และทีม 2v2 พร้อมรองรับ lobby/วงจรการแข่งขัน โดยคงโหมด co-op เดิมไว้

## เป้าหมาย

- เพิ่มห้องแข่งขันที่รองรับผู้เล่น 4 คน
- เพิ่ม Free for All (FFA) 4 คน และ Team Versus 2v2
- รักษาการสร้าง/เข้าห้องและโหมด co-op 2 คน ห้อง A/B ให้ทำงานเหมือนเดิม

## บริบทระบบปัจจุบัน

- Express + Socket.IO; ห้องและ event อยู่ที่ `server/game/rooms.js`
- engine ของด่านอยู่ที่ `server/game/engine.js` และ `server/game/stages/`
- ไคลเอนต์เป็น ES modules ใน `public/js/`; ตรวจ `public/js/net.js` และ UI ปัจจุบันก่อนแก้
- server เป็นเจ้าของสถานะเกมจริงและ ground truth ต้องไม่ส่งให้ client

## FFA 4 คน

- ผู้เล่น 4 คนเข้าแข่งขันในห้องเดียวกัน โดยแยก player ID, ชื่อแสดงผล และตัวตน/สีให้ดูออก
- ทุกคนเล่นโจทย์ชุดเดียวกัน เงื่อนไขเริ่มต้นเดียวกัน และเวลาเริ่มเดียวกัน
- แต่ละคนมี network state ของตนเอง การแก้ค่าของคนหนึ่งไม่เปลี่ยนของคนอื่น เว้นแต่ผลจากระบบไอเทมที่งานที่ 3 ระบุ
- ผู้ชนะคือผู้ที่ผ่านเป้าหมายหลักก่อน หากหมดเวลาให้จัดอันดับตามเป้าหมายสำเร็จ คะแนน และเวลา ตามลำดับ

## Team Versus 2v2

- มี 2 ทีม ทีมละ 2 คน พร้อมแสดงทีมและเพื่อนร่วมทีมใน lobby และหน้าเล่น
- ทั้งสองทีมได้โจทย์และเงื่อนไขเริ่มต้นเดียวกัน
- สมาชิกทีมเดียวกันร่วมแก้ network state ของทีมเดียวกันได้
- ทีมชนะเมื่อทำเป้าหมายหลักสำเร็จก่อน หากหมดเวลาให้จัดอันดับจากคะแนน/เป้าหมายสำเร็จ/เวลา
- การโจมตีของไอเทมต้องมุ่งไปทีมตรงข้าม และห้ามเลือกเพื่อนร่วมทีมเป็นเป้าหมาย

## วงจรการแข่งขัน

1. เลือก FFA หรือ 2v2 แล้วสร้าง/เข้าห้อง
2. Lobby แสดงผู้เล่น 4 ช่อง ชื่อ ตัวละคร ทีม และสถานะพร้อม
3. เริ่มได้เมื่อครบ 4 คนและทุกคนพร้อม
4. เซิร์ฟเวอร์สร้างโจทย์/เงื่อนไขเริ่มต้นเดียวกัน และกำหนด state scope ตามโหมด: รายคนสำหรับ FFA, รายทีมสำหรับ 2v2
5. จบเมื่อมีผู้เล่น/ทีมชนะหรือหมดเวลา จากนั้นส่งผลสรุปและปิดรับการกระทำที่เปลี่ยนเกม

## หน้าจอที่ต้องเพิ่ม

- หน้าเลือกโหมดที่อธิบายความต่างของ FFA และ 2v2
- Lobby 4 ช่อง รองรับสถานะว่าง/รอ/พร้อม/หลุด และการจัดทีม (เลือกวิธีสุ่มหรือเลือกทีมให้ชัด)
- HUD แสดงเวลาและผล/อันดับที่เหมาะกับโหมด
- หน้าสรุปแสดงผู้ชนะ อันดับ คะแนน และผลทีม
- error ที่เข้าใจได้เมื่อห้องเต็ม ผู้เล่นเกิน 4 หรือเริ่มไม่ได้

## ขอบเขตงานและจุดเชื่อมต่อ

- งานนี้เป็นเจ้าของ: ชนิดโหมด, capacity 4, lobby, team assignment, phase การแข่งขัน, เงื่อนไขชนะ/หมดเวลา และ UI เลือกโหมด
- ระบบ progress broadcast เป็นงานที่ 2; ระบบ item spawn/use/effect เป็นงานที่ 3
- ตกลงกับผู้ทำงานที่ 2 และ 3 เรื่องรูปแบบ `mode`, `teamId`, `playerId`, `phase` และ state scope ก่อนรวมโค้ด
- งานนี้ต้องจัดเตรียม player/team identity และการแข่งขันที่งานอื่นใช้ได้ โดยไม่ให้แต่ละงานสร้าง model ห้องซ้ำกัน

## เกณฑ์ยอมรับ

- ห้องแข่งขันรับได้สูงสุด 4 คนและปฏิเสธคนที่ 5 โดยไม่กระทบห้อง co-op เดิม
- FFA และ 2v2 เริ่มได้เมื่อครบและพร้อมตามกติกา
- ผู้เล่นในโหมดเดียวกันได้โจทย์และเงื่อนไขเริ่มต้นเดียวกัน
- FFA แยก state รายผู้เล่น และ 2v2 ใช้ state ร่วมรายทีม
- จบเกมและตัดสินผู้ชนะได้ทั้งกรณีมีผู้ชนะก่อนและหมดเวลา
- reconnect ไม่ทำให้สร้างผู้เล่น/ทีมซ้ำ และ co-op เดิมยังเล่นได้
