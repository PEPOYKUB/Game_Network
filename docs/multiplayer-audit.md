## ทำงานไม่ครบ / มีปัญหา

1. **ไม่มี 2v2 ฝั่ง server เลย** — `mode` รับแค่ `'ffa'|'coop'`; UI ขึ้น "กำลังพัฒนา"
2. **ไม่มีเวลาจำกัด / phase จบ** — การแข่งขันจบเฉพาะเมื่อทุกคนผ่านหรือถอนตัว (`phase` กลับเป็น `select`); มีคน AFK = ค้างตลอด ไม่มี `ended`, ไม่มีการตัดสินเมื่อหมดเวลา, ไม่มี tie-break
3. **ไม่ตรวจว่าผู้เล่นยืนที่สถานีของฝั่งที่สั่ง** — เปิดเทอร์มินัลที่ฝั่ง A แล้วส่ง `role: 'B'` ได้ทันที (`term:exec`/`form:submit` ใช้ `payload.role` แทน `activeRoles`) จึงไม่ต้องเดินไปฝั่ง B
4. **คนแปลกหน้ายึด slot ที่หลุดกลางการแข่งขันได้** — `room:join` ด้วย playerId ใหม่ได้ slot P4 ของคนที่หลุด พร้อม run/อันดับของเขา
5. **progress เป็นจำนวนครั้ง ไม่ใช่ความคืบหน้า** — ไม่มี done/total หรือ %, ไม่มี `version`, `updatedAt` สร้างใหม่ทุกครั้งที่ส่ง, ไม่ throttle
6. **ผู้ถอนตัวไม่อยู่ในอันดับ** — `ffaResults` มีแค่คนที่ผ่าน
7. **FFA ไม่บันทึก leaderboard** และไม่มีหน้าสรุปอันดับรวม (ใช้หน้าจบด่านเดิม + อันดับของตัวเอง)
8. **ไม่มีเทสต์ FFA อัตโนมัติ** ในโค้ดที่ได้มา
9. `items.js`: กิ่ง `item === 'switch'` ใน `useItem` ไม่มีทางทำงาน; `activateSwitch` รบกวนคู่แข่งทุกคนพร้อมกัน (ขัดกับข้อตกลงใหม่ "หนึ่งเป้าหมายต่อครั้ง")
10. **Config Erase/Glitch ยังไม่มีที่ลง** — ด่าน 4, 7, 10 มี `s.state = {}`; ด่านอื่นใช้ key ต่างกัน ต้องให้ด่านประกาศ key เอง

## ข้อตัดสินใจที่ยืนยันแล้ว (7 ต.ค.)

- ผู้เล่น FFA คนเดียวต้องเข้าถึงอุปกรณ์/ข้อมูลของทั้ง A และ B ได้ — โดยต้องเดินไปเปิดเทอร์มินัลที่สถานีของฝั่งนั้น (server ผูก role ของคำสั่งกับสถานีที่เปิดอยู่)
- event contract และกติกาจัดอันดับเป็นแบบเดียวกันทั้ง FFA/2v2 (หน่วยแข่งขัน = scope)
- ไอเทมโจมตีหนึ่งเป้าหมายต่อครั้ง: FFA = คู่แข่ง 1 คน, 2v2 = ทีมตรงข้าม 1 ทีม (รวม Lever)
- Config Erase/Glitch ใช้ได้เฉพาะด่านที่ประกาศ config key; ด่านอื่นปฏิเสธโดยไม่เสียไอเทม
