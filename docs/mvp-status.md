## สิ่งที่แก้ในรอบนี้

### 1. ปุ่มเล่นใหม่ (`stage:retry`)
- Server รับรูปแบบ `(payload, ack)` เหมือน event อื่น และยังรับ `(ack)` แบบเดิมได้ — แก้ `ack is not a function`
- ห้อง FFA/2v2 ถูกส่งต่อไป `competitive.stageRetry` แล้ว (เดิมตกไปที่ handler co-op)

### 2. ผู้มีสิทธิ์โหวต (เล่นใหม่ / ออกจากด่าน)
| โหมด | ผู้มีสิทธิ์โหวต |
|---|---|
| FFA / 2v2 | ผู้เล่นที่ **ออนไลน์และยังไม่ถอนตัว** ในแมตช์ปัจจุบัน |
| co-op (เล่นใหม่หลัง Game Over) | ผู้เล่นที่ **ออนไลน์** |

- คนหลุด/ถอนตัวไม่ถูกนับและไม่บล็อกโหวต; คะแนนโหวตของเขาถูกทิ้ง
- ทุกครั้งที่มีคนหลุด ออกจากห้อง หรือหมดเวลา grace server จะคำนวณโหวตใหม่ — ถ้าคนที่เหลือโหวตครบแล้วจะทำงานทันที
- คนที่กลับเข้ามาก่อนโหวตจบจะกลับเป็นผู้มีสิทธิ์ และต้องโหวตเองอีกครั้ง
- ผู้เล่นที่ถอนตัวแล้ว (หลุดเกิน grace 60 วิ) โหวตไม่ได้ จนกว่าแมตช์ใหม่จะเริ่ม
- ถ้าโหวตเล่นใหม่ครบขณะมีคนออฟไลน์ คนนั้นยังอยู่ในแมตช์ใหม่และได้ grace 60 วิ ตามปกติ

### 3. เริ่มแข่งขันพร้อมกัน (briefing/countdown ฝั่ง server)
- `MODE_CONFIG.briefingMs = 8000` — ทุกแมตช์มีช่วงบรีฟ 8 วินาทีเท่ากันทุกคน
- `match.startsAt` = เวลาเริ่มจริง; นาฬิกาแข่งขัน (`endsAt`) และ `run.startedAt` นับจาก `startsAt`
- ก่อน `startsAt`: เดิน / เปิดคอม / Terminal / ฟอร์ม / คำใบ้ / เก็บ-ใช้ไอเทม ถูก server ปฏิเสธ และไม่มีไอเทม spawn (นาฬิกา spawn เริ่มที่ `startsAt`)
- Event ใหม่: `match:start` มี `startsAt`, `now` และ `match:go` เมื่อเริ่มจริง
- Client: แสดง "เริ่มพร้อมกันใน N" และปิดฉากบรีฟอัตโนมัติตอน `startsAt` (กดข้ามฉากได้ แต่เล่นก่อนเวลาไม่ได้)
- co-op ไม่เปลี่ยนพฤติกรรม (ไม่มี countdown)

- Server: `server/game/solo.js` (ใหม่) — `rooms.js` ส่งห้อง `mode: 'solo'` ไปที่นี่ เหมือนที่ส่ง FFA/2v2 ไป `competitive.js`; co-op, FFA, 2v2 ไม่ผ่านโค้ดนี้
- ใช้เอนจินเดิมทั้งหมด (`startFreshRun`, `execute`, `submitForm`, `revealHint`, `roleView`, `publicRun`) และแผนที่/การเดินจาก `world.js` — ไม่มีโจทย์หรือเอนจินซ้ำ

- Server ตัดสินการผ่านด่าน; client ได้เฉพาะ `roleView` ของฝั่งที่เปิดอยู่และ `publicRun` (ไม่มี truth)
